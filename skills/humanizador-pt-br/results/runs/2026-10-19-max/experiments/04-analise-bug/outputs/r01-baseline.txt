O bug está no argumento padrão mutável `bucket=[]`. Em Python, valores padrão são criados **uma única vez, quando a função é definida**, e não a cada chamada. Assim, chamadas que omitem `bucket` compartilham a mesma lista.

A correção é usar `None` como padrão e criar uma lista dentro da função somente quando necessário:

```python
def collect(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```

Isso garante que:
- Cada chamada sem uma lista receba uma lista nova.
- Uma lista fornecida pelo chamador seja modificada e retornada **sem criar uma cópia**.

### Testes

```python
# Chamadas sem bucket não compartilham estado.
a = collect("A")
b = collect("B")

assert a == ["A"]
assert b == ["B"]
assert a is not b

# Uma lista vazia fornecida pelo chamador é preservada.
bucket = []
result = collect("X", bucket)

assert bucket == ["X"]
assert result is bucket

# Chamadas sucessivas com a mesma lista acumulam itens nela.
result = collect("Y", bucket)

assert bucket == ["X", "Y"]
assert result is bucket

# Uma lista já preenchida também é preservada.
existing = ["inicial"]
result = collect("Z", existing)

assert existing == ["inicial", "Z"]
assert result is existing
```

Evite usar `bucket = bucket or []`: isso substituiria uma lista vazia fornecida pelo chamador por outra lista, violando o requisito de preservar o mesmo objeto.
