# API de tarefas

Cria uma tarefa na fila.

## Endpoint

```http
POST https://api.example.com/v1/jobs
```

## Autenticação

Envie o token no cabeçalho:

```http
Authorization: Bearer <TOKEN>
Content-Type: application/json
```

## Corpo

| Campo | Tipo | Obrigatório | Regras |
|---|---|---|---|
| `name` | string | sim | Não vazia, no máximo 80 caracteres |

```json
{"name":"backup"}
```

## Exemplo

```bash
curl -X POST "https://api.example.com/v1/jobs" \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"name":"backup"}'
```

## Sucesso

HTTP **201 Created**

```json
{"id":"job_123","status":"queued"}
```

`queued` indica que a tarefa entrou na fila.

## Idempotência

`Idempotency-Key` é opcional.

- Por 24 horas, a mesma chave e o mesmo corpo retornam a tarefa existente.
- A mesma chave com corpo diferente retorna **409**.

## Erros

| HTTP | Quando |
|---|---|
| 400 | `name` inválido |
| 401 | Token ausente ou inválido |
| 429 | Mais de 60 requisições por minuto por token; `Retry-After` em segundos |
