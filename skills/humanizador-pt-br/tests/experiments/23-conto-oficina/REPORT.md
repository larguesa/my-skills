## Prompt previsto para as duas condições

Este é o pedido a usar sem e com skill, em chamadas independentes. Não foi utilizado para gerar um texto ainda.

```
Escreva um conto ficcional de 180 a 240 palavras em português brasileiro, em primeira pessoa, narrado por uma aprendiz de relojoaria. Durante o último atendimento antes de fechar a oficina, ela encontra dentro de um relógio parado um bilhete sem assinatura com a frase literal "não acerte a hora". Uma cliente volta para buscar o relógio antes do fechamento. Construa uma cena concreta e um final aberto, sem explicar por completo o bilhete. Entregue somente o conto, sem título, prefácio ou moral final. Não use travessão longo.
```
