# Index

Index of personal skills.

- [humanizador-pt-br](humanizador-pt-br/README.md): makes Brazilian Portuguese text, written from scratch or rewritten from AI-generated text, read like a good human writer's, with facts and voice preserved. Version 0.8.1, no validated gain. [Evaluation](humanizador-pt-br/results/README.md) and [evaluation rules](humanizador-pt-br/AGENTS.md). In Portuguese, by purpose.
- [animation-video-maker](animation-video-maker/README.md): turns a brief into a short explainer, product or typographic video: an editable scene in code and an MP4 exported and checked on your machine, with no video-generation API. 22 styles, 20 examples with the T2S Tech brand and 3 unbranded demos.
- [telegraphist](telegraphist/SKILL.md): economical conversation with the agent, in telegraphic answers, to spend fewer tokens. Measured on an interrupted sample without judges: shorter answers and higher total tokens; preservation of information not verified. [Test report](telegraphist/tests/REPORT.md).
- [claude-code-user](claude-code-user/SKILL.md): guide for the agent to use Claude Code headless (`claude -p`): when to delegate, flags, permissions, resume, guard hook and verification, with the official docs in markdown. Tested on 2.1.316.
- [pi-user](pi-user/SKILL.md): guide for the agent to use pi (pi.dev) headless (`pi -p --mode json`): when to delegate, JSON events, sessions, RPC, models, native MCP, guard extension and verification, with the official docs in markdown. Tested on 1.4.0.
- [opencode-user](opencode-user/SKILL.md): guide for the agent to use OpenCode headless (`opencode run --format json`): when to delegate, JSON events, sessions, server, agents, models, MCP, guard permission rules and verification, with the official docs in markdown. Tested on 1.19.5.
- [codex-user](codex-user/SKILL.md): guide for the agent to use the OpenAI Codex CLI headless (`codex exec --json`): when to delegate, JSON events, sandbox and approvals, guard rules, sessions, review, AGENTS.md, skills, MCP, usage limits and verification, with the official docs in markdown. Checked on codex-cli 0.166.0, model runs not tested.
- [antigravity-user](antigravity-user/SKILL.md): guide for the agent to use the Google Antigravity CLI headless (`agy -p --output-format stream-json`): when to delegate, JSON events, silent permission denials, guard rules, execution modes and sandbox, resume, structured output, repository hooks, AGENTS.md, skills, MCP, quotas and verification, with the official docs in markdown. Tested on agy 1.4.2 (Windows).
- [agentic-orchestrator](agentic-orchestrator/SKILL.md): orchestration of several agents through natural language only, no frameworks or scripts: the host agent delegates to subagents or to other command-line agents and keeps flow, contracts, state and handoffs in YAML, JSON or Markdown. 19 flow patterns, communication patterns, loop and graph engineering, verification, judge panels and consensus. Examples checked for format; no evaluation with and without the skill.
