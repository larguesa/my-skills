## Fill before production

- **Brief:** audience, one proposition, factual sources, language, intended viewing size.
- **Format:** duration, dimensions, fps, silent/audio, loop or closing hold, delivery destination.
- **State or shot table:** absolute start/end, visible action, invariant, exact copy, evidence, reading hold, transition and audio cue.
- **Asset ledger:** file, owner, source, permitted use, license/permission evidence, attribution, edits and privacy redactions.
- **Acceptance:** source agreement, readable holds, continuity, accessibility, repeatable frames and actual encoded output.

Timings below are editable examples, not universal attention rules. Delete beats before accelerating text. None requires music, paid generation, a brand frame or a CTA. Recompose separately for each ratio.
