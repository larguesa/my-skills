# Guard permission rules
`guard-permissions.json` holds OpenCode `permission` deny rules: bash `git push*`, mutating `curl -X POST/PUT/DELETE/PATCH`, anything mentioning `.secrets`, `rm -rf /`; read/edit of `*.env`, `*/.secrets/*`, `*auth.json`. Merge it into `~/.config/opencode/opencode.json` (back up first): `jq -s '.[0] * .[1]' opencode.json guard-permissions.json > new.json`, review, replace. Or apply per run with `OPENCODE_PERMISSION="$(jq -c .permission guard-permissions.json)"`. Rules use wildcards and the last match wins (docs/permissions.md). The model sees the denial as a tool error. A tripwire, not a sandbox.
